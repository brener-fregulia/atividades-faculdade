**EXERCICIOS**

<ol>
<li> Crie uma aplicação simples em PHP que crie uma variável com seu nome e outra variável com sua idade e mostre na tela.</li>

<li> Altere a aplicação do exercício 1, para que o nome e a idade possam ser informados através de dados de um formulário html.</li>

<li> Crie uma aplicação onde seja informado o nome e de uma pessoa e sua data de nascimento e a aplicação retorne se essa pessoa é maior ou menor de idade (use funções e objetos de data para manipular a data e calcular a idade).</li>

<li> Crie uma aplicação que receba através de um formulário um valor e liste em tela os números pares de 0 até o valor informado.</li>

<li> Crie uma aplicação que sorteie números para a Mega Sena (sorteia seis números de 0 a 60 sem repetir).</li>

<li> Aprimore esse exercício anterior para após sortear permitir salvar o sorteio em um arquivo texto (Guarde a Data e os números sorteados).</li>

<li> Crie uma aplicação com um formulário que peça o nome de pessoas e guarde em um vetor na sessão. Ter uma opção que exibe todos os nomes guardados.</li>

<li>Crie uma aplicação que monte um formulário de contato e envie esse formulário de dados para seu e-mail. Use a função PHP Mailer.</li>
</ol>
